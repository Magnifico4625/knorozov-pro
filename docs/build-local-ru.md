# Бесплатная сборка установщиков на своём компьютере

GitHub Actions для этого не нужен, банковская карта не требуется. Windows-установщик собирается на Windows 10/11 x64,
а Mac-установщик — на Mac с Apple Silicon (M1, M2 и новее). Для M1 и M2 подходит один и тот же файл `macOS-arm64`.
Инструменты разработки устанавливаются только на компьютеры, где выполняется сборка;
пользователям готового установщика они не нужны.

## 1. Скачать проект

Откройте [репозиторий](https://github.com/Magnifico4625/knorozov-pro), выберите ветку **main**,
нажмите **Code → Download ZIP** и распакуйте архив. Если используете Git, получите текущую `main`.
Для доступа к приватному репозиторию войдите в GitHub. Само скачивание кода и создание Release не требуют карты.

## 2. Подготовить компьютер один раз

### Windows 11

Установите:

1. [Node.js](https://nodejs.org/en/download) **22 LTS, Windows x64**.
2. [Build Tools for Visual Studio 2022](https://visualstudio.microsoft.com/downloads/#build-tools-for-visual-studio-2022).
   В установщике выберите **«Разработка классических приложений на C++» / Desktop development with C++**;
   оставьте выбранными MSVC и Windows SDK. Полная платная Visual Studio не нужна.
3. [Rust](https://rustup.rs/) — запустите `rustup-init.exe` и выберите стандартную установку MSVC x64.
4. [CMake](https://cmake.org/download/) — Windows x64; рекомендуется версия
   [3.31.6](https://github.com/Kitware/CMake/releases/tag/v3.31.6).
   В установщике включите **Add CMake to the system PATH**.
5. [LLVM](https://github.com/llvm/llvm-project/releases) — официальный Windows x64 установщик.
   Стандартная папка `C:\Program Files\LLVM` определяется скриптом автоматически.
   При установке в другую папку задайте `LIBCLANG_PATH` — путь к папке с `libclang.dll`.

После установки откройте **новое** окно терминала: только оно получит обновлённые пути к инструментам.
Microsoft WebView2 обычно уже есть в Windows 11; Tauri включает его загрузчик в установщик приложения.

### MacBook M1/M2

1. Откройте **Терминал**, выполните `xcode-select --install` и дождитесь завершения установки Command Line Tools.
2. Установите [Node.js](https://nodejs.org/en/download) **22 LTS, macOS ARM64**.
3. Установите [Rust](https://rustup.rs/) стандартным способом, указанным на его сайте.
   Нужна нативная версия `aarch64-apple-darwin`; запускайте терминал без Rosetta.
4. Установите [CMake 3.31.6](https://github.com/Kitware/CMake/releases/tag/v3.31.6):
   `cmake-3.31.6-macos-universal.dmg`, перенесите CMake в **Программы**.

Откройте новое окно терминала. Чтобы оно находило CMake и Rust, выполните:

```bash
export PATH="/Applications/CMake.app/Contents/bin:$PATH"
source "$HOME/.cargo/env"
```

Если Node.js, Rust и CMake уже установлены, используйте существующие подходящие версии.
Нужен Node.js 22.12+ из ветки 22 либо 24+, pnpm 10 и актуальный стабильный Rust.

## 3. Собрать установщики

Откройте терминал **в распакованной папке проекта**, где лежит `package.json`.
В Windows можно нажать на папку правой кнопкой и выбрать **«Открыть в терминале»**.
На Mac перейдите в папку командой `cd`: например, `cd ~/Downloads/knorozov-pro-main`.

**Windows, PowerShell:**

```powershell
npx.cmd --yes pnpm@10 installers
```

**Mac, Терминал:**

```bash
npx --yes pnpm@10 installers
```

Команда скачает pnpm во временный кеш Node.js, установит зависимости проекта по lock-файлу,
проверит интерфейс, соберёт приложение и установщик. Глобальная установка pnpm не требуется.
Если pnpm 10 уже установлен, можно выполнить `pnpm installers` (в Windows — `pnpm.cmd installers`).
Первой сборке нужен интернет для инструментов и библиотек. Не закрывайте терминал до сообщения **«Готово»**.
При ошибке команда остановится и выведет причину; пришлите последние строки вывода для диагностики.

## 4. Найти результат

| Компьютер сборки | Папка внутри проекта | Файлы для версии 0.1.0 |
|---|---|---|
| Windows x64 | `out/windows-x64` | `Knorozov-PRO_0.1.0_Windows-x64-setup.exe` |
| Mac M1/M2 и новее | `out/macos-arm64` | `Knorozov-PRO_0.1.0_macOS-arm64.dmg`, `Knorozov-PRO_0.1.0_macOS-arm64.pkg` |

В каждой папке также будет `SHA256SUMS.txt` с контрольными суммами файлов **этой платформы**.
Номер версии берётся из проекта. Установщик можно скопировать на другой компьютер с той же ОС и архитектурой.
Проверьте его установку и реальную расшифровку; сборка сама по себе не проверяет качество распознавания.
Порядок установки и первый запуск описаны в [руководстве](install-ru.md).

Чтобы файлы можно было скачивать с GitHub, откройте **Releases → Draft a new release**,
выберите текущий коммит `main` и тег новой версии, например `v0.1.0`, и перетащите готовые установщики в **Assets**.
Сохраните черновик до завершения проверки установки. Для объединения контрольных сумм двух платформ
соедините строки их `SHA256SUMS.txt` в один файл. Публикация файлов Release не требует запуска GitHub Actions.
В приватном репозитории скачать их смогут пользователи с доступом к нему.

Подпись Windows и нотарификация macOS пока не настроены. Этот способ не создаёт установщик для Intel-Mac.
