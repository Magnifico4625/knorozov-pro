Кнорозов PRO — офлайн-приложение для расшифровки аудио и видео.

Выберите установщик для своего компьютера:

- **Windows 10/11, x64:** установщик с окончанием `Windows-x64-setup.exe`.
- **macOS, Apple Silicon (M1 и новее):** установщик с окончанием `macOS-arm64.dmg` или `macOS-arm64.pkg`.

Модели распознавания скачиваются при первом запуске; дальнейшая расшифровка работает без интернета. Записи остаются на вашем компьютере. При недоступности Hugging Face можно выбрать зеркало в настройках.

Поддерживаются русский, английский и другие языки Whisper, разделение по спикерам, редактирование текста и экспорт в Word, PDF, TXT и SRT.

Эти сборки пока не подписаны и не нотарифицированы. Инструкции для первого запуска и системные требования — в [руководстве по установке](https://github.com/Magnifico4625/knorozov-pro/blob/main/docs/install-ru.md). Контрольные суммы установщиков находятся в приложенном файле `SHA256SUMS.txt`.
