# Установка Кнорозов PRO

Сборки пока **не подписаны** сертификатом разработчика, поэтому Windows и macOS при первом запуске
показывают предупреждение. Это нормально — ниже написано, как его обойти. Программа ничего не отправляет
в интернет: сеть нужна только один раз, чтобы скачать модели распознавания (~760 МБ).

## Где взять файлы

Откройте [Releases](https://github.com/Magnifico4625/knorozov-pro/releases), выберите опубликованную версию
и скачайте файл из раздела **Assets**:

* Windows x64: `Knorozov-PRO_<версия>_Windows-x64-setup.exe`.
* Mac с Apple Silicon: `Knorozov-PRO_<версия>_macOS-arm64.dmg` или `Knorozov-PRO_<версия>_macOS-arm64.pkg`.

Файл `SHA256SUMS.txt` содержит контрольные суммы установщиков. Если опубликованных версий пока нет,
проверочные сборки можно скачать в **Actions → последний зелёный запуск CI → Artifacts**:
`Knorozov-PRO-windows-x64` или `Knorozov-PRO-macos-arm64`.
Для скачивания артефактов нужна учётная запись GitHub; они хранятся 30 дней и скачиваются в zip-архиве,
который нужно распаковать. Черновик Release становится доступен пользователям после публикации владельцем.

## Windows 10/11

1. Запустите `Knorozov-PRO_…_Windows-x64-setup.exe`.
2. Если появилось синее окно **«Windows защитила ваш компьютер»** (SmartScreen):
   нажмите **«Подробнее»** → **«Выполнить в любом случае»**.
3. Установщик ставит программу только для текущего пользователя (права администратора не нужны).
   Если на компьютере нет компонента Microsoft WebView2 (бывает на старых Windows 10), установщик скачает его сам.
4. Запустите «Кнорозов PRO» из меню «Пуск».

Требования: 64-битная Windows 10/11, процессор с поддержкой AVX2 (почти все Intel с 2013 г. и AMD с 2015 г.),
8 ГБ ОЗУ (для режима «Точно» желательно 16 ГБ), ~2 ГБ свободного места.

## macOS (Apple Silicon: M1/M2/M3/M4)

### Вариант A — DMG
1. Откройте `Knorozov-PRO_…_macOS-arm64.dmg` и перетащите «Кнорозов PRO» в папку **Программы**.
2. Первый запуск: в Finder откройте **Программы**, нажмите на «Кнорозов PRO» **правой кнопкой (или Ctrl+клик) →
   «Открыть»** → в окне «Не удаётся проверить разработчика» снова **«Открыть»**.
3. На macOS 15 (Sequoia) и новее, если кнопки «Открыть» нет: попробуйте открыть программу, закройте предупреждение,
   затем **Системные настройки → Конфиденциальность и безопасность** → внизу «Кнорозов PRO заблокирован…» →
   **«Всё равно открыть»** → введите пароль.

### Вариант B — PKG
1. Откройте `Knorozov-PRO_…_macOS-arm64.pkg` правой кнопкой → **«Открыть»** (или через
   «Конфиденциальность и безопасность» → «Всё равно открыть», как выше) и пройдите установку.
2. Программа появится в папке **Программы**; при первом запуске может понадобиться тот же шаг с «Открыть».

### Если macOS пишет «Приложение повреждено и не может быть открыто»
Это тоже следствие отсутствия подписи. Откройте **Терминал** и выполните:

```bash
xattr -dr com.apple.quarantine "/Applications/Кнорозов PRO.app"
```

Требования: macOS 11+ на Apple Silicon. Intel-Mac в версии 0.1 не поддерживается.

## Первый запуск

Программа скачает две модели распознавания: «Быстро» (190 МБ) и «Точно» (574 МБ).
Загрузку можно отменить и продолжить позже — она докачивается с того же места, а файл проверяется по контрольной сумме.

Если загрузка не идёт (Hugging Face бывает недоступен из России): **Настройки (шестерёнка) → Модели распознавания →
Адрес для загрузки моделей** → выберите «hf-mirror.com (зеркало)» или укажите свой адрес и нажмите «Скачать».
Можно положить файлы моделей на свой сервер и указать адрес вида `http://сервер/models/{file}`.

После этого интернет больше не нужен.

## Где хранятся данные

* Windows: `%APPDATA%\pro.knorozov.app\` (модели — в `models`, расшифровки — в `projects`)
* macOS: `~/Library/Application Support/pro.knorozov.app/`

Удалить модели можно в настройках. Экспортированные файлы по умолчанию сохраняются в папку «Документы»
(меняется в настройках).
