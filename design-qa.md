# Проверка лендинга

final result: passed

Проверена локальная производственная сборка страницы. Публикация GitHub Pages и
реальная сборка установщиков оцениваются отдельно: на момент проверки задания GitHub
не стартуют из-за блокировки billing. Настройка Pages включена пользователем и
подтверждена через API (`build_type: workflow`); публикация ещё не выполнена.

## Эталон и сравнение

Эталон — приложенное пользователем изображение «Кнорозов PRO_ офлайн-расшифровка аудио.png»
размером 1055×1490. Оно доступно в разговоре; указанный Windows-путь отсутствует
в облачной Linux-среде. Сравнение выполнено визуально с изображением в разговоре
и снимками страницы при ширине 1055 px. Объединённая растровая картинка сравнения
не создавалась, пиксельное совпадение не заявляется.

Проверены расположение навигации, заголовок с синим словом «офлайн», кнопки Windows/macOS,
значок приватности, фон с горным озером, превью приложения, две карточки установщиков,
четыре карточки возможностей, три шага и нижние ссылки.

Использованы действующий логотип и превью из репозитория. Фотография горного озера
создана отдельно. Текст приведён к реальным возможностям: выжимка по записи не
реализована и не обещается; время обработки зависит от записи и компьютера.
Добавлены сведения об Apple Silicon, первой загрузке моделей и фактической готовности
установщиков. Из-за этих дополнений высота страницы отличается от эталона.

## Итерации

1. Первое сравнение: скорректированы высота и положение горного фона, расстояния возле
   кнопок, размер кнопки macOS и плотность карточек возможностей.
2. Повторное сравнение всей страницы и отдельных участков: сохранены структура,
   читаемость и акценты эталона. Проверена адаптация для телефона.

Блокирующих визуальных дефектов после исправлений не обнаружено.

## Браузерная проверка

Использованы Playwright и системный Chromium, поскольку встроенный Browser tool
в этой среде недоступен. Проверялись настоящие HTML/CSS/JS, шрифт и изображения из
производственной сборки. Ответы API Releases и файлов установщиков имитировались;
проверка кликов не подтверждает сборку настоящих бинарных файлов.

20 сценариев прошли: отсутствие выпуска, появление опубликованных EXE/DMG/PKG,
обновление версии и размера, переходы и скачивания, исключение черновиков и prerelease,
неполный набор файлов, отклонение постороннего домена, резервные ссылки при ошибке API,
удаление устаревшей ссылки PKG при обновлении выпуска, доступное имя мобильной ссылки GitHub,
навигация с клавиатуры, видимый фокус, reduced motion и размеры 320, 390, 820, 1440 px.
Горизонтального переполнения, отсутствующих локальных ресурсов и неожиданных ошибок
JavaScript не обнаружено. Ответ HTTP 503 был намеренно задан в сценариях отказа API.

Снимки и подробные результаты сохранены в рабочем облачном пространстве:
`/workspace/knorozov-review/screenshots/landing-final-desktop.png`,
`landing-final-hero.png`, `landing-final-downloads.png`, `landing-final-mobile.png`
и `/workspace/knorozov-review/landing-qa.json`.
